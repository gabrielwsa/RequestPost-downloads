## Instalação

Abra a [página de releases](../../releases/latest) e baixe o arquivo do seu sistema:

| Sistema | Arquivo | Como instalar |
|---|---|---|
| **Windows** | `RequestPost Setup x.y.z.exe` | Execute o instalador. Se aparecer "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**. |
| **Arch Linux** | `RequestPost-x.y.z-x86_64.pkg.tar.xz` | `sudo pacman -U RequestPost-*.pkg.tar.xz` (aparece no menu de aplicativos; remova com `sudo pacman -R RequestPost`). |
| **Linux** (qualquer distro) | `RequestPost-x.y.z.AppImage` | `chmod +x RequestPost-*.AppImage` e execute. |
| **macOS** (Apple Silicon) | `RequestPost-x.y.z-arm64.dmg` | Arraste para Aplicativos. Na primeira vez, clique com o botão direito no app → **Abrir**. |

Os instaladores ainda não têm assinatura digital, por isso o Windows e o macOS pedem confirmação na primeira execução.

Os seus dados (coleções, ambientes, flows) ficam no seu computador.
